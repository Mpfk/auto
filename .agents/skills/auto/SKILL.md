# Auto

Read `docs/auto/playbooks/core.md`, `docs/auto/playbooks/github.md`, and
`docs/auto/playbooks/auto.md` completely, then follow them.

Explicit `$auto` invocation grants autonomous gate authority for the scoped
issue. If this skill was selected implicitly for an ordinary implementation
request, use interactive Gate 1 and Gate 2 instead.
